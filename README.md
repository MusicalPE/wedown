# 위 Down · 맨몸 판정기

맨몸으로, 나답게, 바다 끝까지.

카메라로 관절 움직임을 읽어 **제대로 한 맨몸 운동만** 세는 판정기예요. 한 번 할 때마다 바다로 40cm씩 내려가요.

- 판정기 주소: https://musicalpe.github.io/wedown/checker/
- 맨 앞 주소(https://musicalpe.github.io/wedown/)는 앞으로 우리 학교 기록 메인 페이지가 될 자리예요.
- 지금 되는 운동: 스쿼트, 점핑잭
- 영상은 기기 안에서만 처리되고 어디에도 저장·전송되지 않아요.
- 처음 열 때 관절 인식 모델(약 6MB)을 받아야 해서 인터넷이 필요해요.

## 쓰는 법

1. 판정기 주소를 태블릿·휴대폰·노트북 크롬으로 열어요. (파일로 열면 카메라가 막혀요)
2. 운동을 고르고 "카메라 켜고 시작하기"를 눌러요.
3. 스쿼트는 엉덩이·무릎·발목이 다 보이게(옆으로 서면 더 정확), 점핑잭은 정면으로 머리부터 발까지 보이게 서요.
4. "시작"을 누르고 운동해요. 기준(쉽게·보통·엄격하게)은 아래에서 바꿀 수 있어요.

주소 뒤에 `?ex=jack`을 붙이면 점핑잭으로 바로 열려요.

## 판정 방식

- 스쿼트: 서 있는 자세를 기준으로 엉덩이가 무릎 높이 쪽으로 내려간 깊이를 재요. 선을 넘게 앉았다가 다 일어나야 1회.
- 점핑잭: 두 팔은 어깨 위로, 두 발은 어깨너비보다 넓게 벌렸다가 다시 모으면 1회.
