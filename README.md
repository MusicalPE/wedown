# 위 Down · 우리 Down 맨몸 운동 기록

맨몸으로, 나답게, 바다 끝까지.

카메라로 관절 움직임을 읽어 **제대로 한 맨몸 운동만** 세고, 우리 반이 함께 바다 속으로 내려가는 기록 프로그램이에요. 한 번 할 때마다 바다로 40cm씩 내려가요.

- 학교 기록(우리 Down): https://musicalpe.github.io/wedown/ — 학교 시트와 연결해서 써요
- 판정기만 쓰기: https://musicalpe.github.io/wedown/checker/
- 지금 되는 운동: 스쿼트, 점핑잭, 런지, 버피, 팔굽혀펴기, 윗몸일으키기, 플랭크(시간), 무릎 높이 들기, 외발 서기(시간), 마운틴 클라이머, 레그 레이즈
- 영상은 기기 안에서만 처리되고 어디에도 저장·전송되지 않아요.
- 처음 열 때 관절 인식 모델(약 6MB)을 받아야 해서 인터넷이 필요해요.

## 학교 기록 설치 (처음 한 번)

1. 구글 드라이브에서 새 스프레드시트를 만들고 `6학년 1반 위다운`처럼 이름을 붙여요.
2. **확장 프로그램 → Apps Script** 를 열고, 이 저장소의 `Shell.gs` 내용을 통째로 붙여넣고 저장해요.
3. **배포 → 새 배포 → 유형: 웹 앱** — 다음 사용자로 실행: **나**, 액세스 권한: **모든 사용자** → 배포 → 권한 허용
4. 나온 웹 앱 주소(…/exec)를 열면 "설치 확인" 화면이 떠요. **프로그램 열기**를 누르고 그 주소를 즐겨찾기에 넣어요.
5. **관리자**(처음 비밀번호 1234 — 꼭 바꿔 주세요)에서 반 이름·학생 명단·기본 계획(횟수·세트·쉬는 시간)을 정해요.

화면은 이 저장소에서 열리니까 새 판이 나오면 저절로 바뀌어요. 껍데기(Shell.gs)를 바꿔야 할 때만 화면이 알려 줘요.

### 학교 기록에서 하는 일

- **메인**: 우리 반이 함께 내려간 바다 깊이(이정표: 200m 햇빛 끝 → 1,000m 심해 → 3,800m 타이타닉 → 11,000m 마리아나 해구), 학생마다 다이빙 줄, 이번 주 다이버, 오늘 들어온 기록
- **오늘 운동하기**: 이름을 누르고 카메라로 시작 → 판정기가 센 횟수만 학교 기록에 들어가요 (손으로 넣는 칸은 없어요)
- **운동방**(선생님): QR·방 번호로 학생들이 각자 기기로 들어오고, 선생님이 과제(예: 스쿼트 15회 × 3세트)를 보내면 각자 판정기로 해요. 선생님 화면에는 숫자 대신 **1세트 완료 · 2세트 완료 · 끝!** 신호만 떠요(3초마다 새로 고침). 학생들 화면에도 함께 들어온 친구들의 세트 완료가 작게 보여요(번호 순, 내 화면이 가장 크게). 방 자료는 시트에 쓰지 않고 구글 임시 저장소에만 두었다가 몇 시간 뒤 저절로 사라지고, 다 마친 결과만 기록으로 남아요.
- **하루 안내**: 한 학생이 같은 종목을 하루에 정한 개수(기본 100개)를 넘기려 하면 "몸 상태에 맞춰 무리하지 마세요"가 떠요.

## 판정기 쓰는 법

1. 판정기 주소를 태블릿·휴대폰·노트북 크롬으로 열어요. (파일로 열면 카메라가 막혀요)
2. 운동을 고르고 "카메라 켜고 시작하기"를 눌러요.
3. 스쿼트는 엉덩이·무릎·발목이 다 보이게(옆으로 서면 더 정확), 점핑잭은 정면으로 머리부터 발까지 보이게 서요.
4. 화면 아래에서 횟수·세트·쉬는 시간을 정하고 "시작"을 눌러요. 5초를 센 뒤 1세트가 시작되고, 세트 사이에는 정한 만큼 쉬어요. 기준(쉽게·보통·엄격하게)도 아래에서 바꿀 수 있어요.
5. 판정기만 쓸 때는 기록장(이 기기)에 담겨요. 학교 기록에서 이름을 골라 열었을 때는 학교 시트로 들어가요. 하루에 같은 종목을 100개 넘게 하면 무리하지 말라는 안내가 떠요.

주소 뒤에 `?ex=jack`을 붙이면 점핑잭으로 바로 열려요.

## 판정 방식

- 스쿼트: 서 있는 자세를 기준으로 엉덩이가 무릎 높이 쪽으로 내려간 깊이를 재요. 선을 넘게 앉았다가 다 일어나야 1회.
- 런지: 다리를 앞뒤로 벌리고 뒷무릎을 바닥 쪽으로 내렸다가 다시 모아 똑바로 서면 1회(왼발·오른발 각각 1회). 다리를 안 벌리고 앉으면 세지 않음.
- 버피: 엎드려 버티기 → 다시 일어서기 → 만세 점프(두 손 머리 위, 두 발이 뜸)까지 이어지면 1회. 기준 '쉽게'는 점프를 보지 않음.
- 팔굽혀펴기: 옆에서 볼 때 몸이 바닥과 나란한 채로 팔꿈치를 굽혀 내려갔다가 다시 펴면 1회. 서서 팔만 굽히면 세지 않음.
- 윗몸일으키기: 누운 자세에서 몸통이 기준 각도(보통 62°)까지 일어나면 1회, 다시 누워야 다음 회.
- 플랭크: 팔을 수직으로 세워(또는 팔꿈치로) 바닥을 짚고 머리부터 발끝까지 비스듬한 한 줄로 곧을 때만 초가 올라감. 바닥에 엎드려 누우면 세지 않음. 엉덩이가 처지거나 솟으면 멈추고, 바로잡으면 이어서. 목표 시간은 선생님이 관리자 설정·운동방 과제에서 정함. 바다 깊이는 2초 = 1회(40cm).
- 무릎 높이 들기: 제자리에서 무릎이 엉덩이 높이 가까이 올라오면 1회(왼쪽·오른쪽 각각).
- 외발 서기: 몸을 세우고 한 발을 든 동안 초가 올라감, 왼발·오른발 시간을 따로 보여 줌. 목표 시간은 플랭크와 같은 '버티기 목표 시간'.
- 마운틴 클라이머: 팔을 세운 엎드린 자세(옆모습)에서 무릎을 가슴 쪽으로 당겼다 펴면 1회(다리마다).
- 레그 레이즈: 바로 누워 다리를 편 채로 기준 각도(보통 60°)까지 들면 1회, 다시 내려야 다음 회. 무릎을 굽히면 세지 않음.
- 점핑잭: ① 다리 벌리고 팔 어깨 높이 → ② 차렷 → ③ 다리 벌리고 만세 → ④ 차렷, 박자마다 두 발로 콩 뛰면서 네 박자를 순서대로 다 하면 1회. (기준 '쉽게'에서는 점프를 보지 않음)

## 판 기록

- v0.1.0 — 첫 시제품 (스쿼트·점핑잭 판정, 바다 깊이 표시, 직접 센 숫자와 비교); 판정기는 checker/ 폴더, 맨 앞은 안내 페이지
- v0.1.1 — 핸드폰 세로 화면에서 내 모습과 횟수를 한 화면에 (줄넘기 판정기와 같은 배치), 시작 버튼은 아래에 붙음
- v0.1.2 — 스쿼트 판정 고침: 실제로 앉아도 안 세던 것(깊이를 두 가지로 재고 기준을 낮춤), 카메라로 다가가거나 발이 화면 밖으로 나갈 때 잘못 세던 것(발 위치가 바뀌면 기준을 다시 잡음)
- v0.1.3 — 점핑잭을 네 박자(어깨 높이 → 차렷 → 만세 → 차렷)가 1회가 되게 바꿈; 한 번 벌렸다 모으기만으로는 세지 않음
- v0.1.4 — 점핑잭 박자마다 두 발이 함께 떴는지(점프) 확인; 걸어서 발을 옮기면 세지 않음, 기준 '쉽게'는 점프 확인 없음
- v0.2.0 — 운동 계획: 횟수·세트·쉬는 시간을 정하고, 5초 세고 시작 → 세트 → 쉬는 시간 → 다음 세트 → 끝나면 기록장(이 기기)에 저장. 하루에 같은 종목이 100개를 넘으면 '무리하지 마세요' 안내
- v0.3.0 — 학교 기록(우리 Down) 첫 판: 학교 시트 껍데기(Shell.gs), 메인(바다 깊이 자·다이빙 줄·이번 주 다이버·오늘 기록), 관리자(반 이름·학생 붙여넣기 등록·기본 계획·하루 안내 기준·비밀번호·기록 지우기), 운동방(QR 입장·과제 보내기·세트 완료 신호, 임시 저장소만 사용), 판정기 학교 연결(계획 고정·끝나면 학교 기록 저장·학생별 하루 안내)
- v0.3.1 — 운동방에서 함께 들어온 친구들의 세트 완료를 작게 보여 줌(입장 화면·판정기 아래 한 줄). 번호 순으로 고정해 빠르기를 겨루지 않게, 내 화면은 그대로 크게
- v0.4.0 — 런지·버피 추가 (판정기·학교 기록·운동방 과제 모두). 기기를 놓아 두고 사람이 방향을 돌면 되고, 옆으로 서면 더 정확함
- v0.5.0 — 팔굽혀펴기·윗몸일으키기·플랭크 추가. 플랭크는 자세가 맞는 동안만 초가 올라가고, 목표 시간은 선생님이 정함(관리자 설정·운동방 과제)
- v0.5.1 — 플랭크: 바닥에 엎드려 누운 것은 세지 않음(어깨가 팔로 들려 있어야 함), 팔을 수직으로 세운 비스듬한 일직선 자세도 인정, 머리까지 한 줄인지 확인. 시작을 누르면 종목·설정 칸이 숨고 카메라와 숫자가 크게 보이게 화면이 내려감
- v0.6.0 — 무릎 높이 들기·외발 서기(시간)·마운틴 클라이머·레그 레이즈 추가 (모두 11종목)
