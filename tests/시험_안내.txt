위 Down 올리기 전 시험

1. 단순 수정(글귀, 색, 여백, 그림 교체) → 코드 검사만
     node tests/check.js
   보는 것: 문법 오류(따옴표·괄호 짝), 태그 따옴표 짝, 단추가 가리키는 함수·칸(id)이 실제로 있는지,
            같은 id 겹침, 판 번호(학교 화면·판정기·README·껍데기)가 서로 맞는지,
            화면이 부르는 서버 기능이 껍데기(Shell.gs)에 다 있는지

2. 기능 수정(새 기능, 화면 배치 변경, 서버·저장 방식 수정) → 전체 시험
     python3 tests/full.py        (-v 를 붙이면 통과한 항목도 다 보여 줌)
   코드 검사 + 판정 시험(tests/judge.test.js) + 가짜 학교 시트로 화면을 실제로 띄워서:
     관리자 로그인·설정 저장 / 학생 등록·고치기·비밀번호 초기화 /
     메인에서 학년·반·이름·비밀번호 → 판정기 → 세트 끝 → 학교 기록 저장 /
     하루 안내 / 플랭크 초 저장 / 운동방 입장·과제·끝 신호 / 혼자 쓰는 판정기 종목 바꾸기·기록장 /
     학생 QR / 바다 놀이터 / 휴대폰·태블릿·노트북에서 옆으로 밀리지 않는지 / 화면 오류

3. 애매하면 전체 시험. 하나라도 걸리면 올리지 않고 먼저 고침.
4. 진짜 학교 시트는 건드리지 않음(tests/mock-server.js 가 가짜 시트로 Shell.gs 를 돌림).
